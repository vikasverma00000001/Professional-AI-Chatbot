#  Professional AI Chatbot

##  Project Overview

Professional AI Chatbot is an intelligent conversational application developed using Python, Flask, and Google's Gemini API.
The chatbot uses Generative AI and Natural Language Processing (NLP) to understand user queries and generate meaningful, context-aware responses.
It provides an interactive chat interface where users can communicate with an AI assistant and receive responses in real time.

##  Technologies Used

- Python
- Flask
- Google Gemini API
- Generative AI
- Natural Language Processing (NLP)
- HTML
- CSS
- JavaScript
- REST API
- python-dotenv

##  Project Workflow

1. User enters a message in the chatbot interface.
2. The frontend sends the message to the Flask backend.
3. Flask processes the incoming request.
4. The Gemini API generates an AI-based response.
5. The backend receives the generated response.
6. The chatbot displays the response to the user.
